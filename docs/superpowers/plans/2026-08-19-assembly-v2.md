# Assembly v2 Implementation Plan (PRD-013 MVP)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give AgentCAD real assembly structure — instance patterns, cross-project sub-assemblies, slider/planar joints, simplified proxy meshes with instanced rendering, and URDF export — all through one expansion point and the extension-point contract.

**Architecture:** A single server-side expansion (`core/mates.expand`) turns patterns + sub-assemblies into a flat concrete instance list that every consumer already reads via `service._resolved_instances`; transform geometry is composed in the kernel via build123d `Location` (one rotation convention). New tool packs (`tools_structure`, `tools_urdf`), a route pack (`routes_structure`), a worker handler pack (`handlers/simplify`), the connectors resolver grown in place, and OCP-free `core/urdf.py`. No edits to `worker.py`/`tools.py`/`app.py`/`service.py` cores.

**Tech Stack:** Python 3.12 + uv, build123d/OCCT (kernel only), scipy (convex hull), FastAPI, Three.js 0.185.1 (frontend), pytest (8-way parallel).

**Design spec:** `docs/superpowers/specs/2026-08-19-assembly-v2-design.md` — read it first; every decision number below refers to it.

**Slice count (9) & justification:** 005a/007 were 6–8 slices for single-surface features. PRD-013 spans six FR groups across two processes plus the frontend plus a new export format, so 9 vertical slices (each independently testable and reviewable) is proportionate, not padded. **Recommended PR seam:** slices 1–4 (structure + joints, all server/kernel, headless-testable) as PR-A; slices 5–9 (scale render + URDF + UI + docs) as PR-B. One PR for the whole MVP is too large for a fair review.

## Global Constraints

- **Only `agentcad/kernel/` imports OCP/build123d.** `core/urdf.py`, `core/mates.py` expansion, and all `tools_*`/`routes_*` stay OCP-free.
- **Never edit** `worker.py` / `tools.py` / `app.py` / `service.py` cores — extension packs and `core/` modules only.
- **Do NOT touch sandbox/confinement code** — PRD-006 is in flight on another branch touching kernel execution; stay in packs (`handlers/simplify.py`, the connectors resolver logic), low conflict.
- **Rotations are intrinsic XYZ Euler degrees everywhere** — never add a second server-side Euler implementation; compose transforms in the kernel via `Location`.
- Boolean intersection uses `&`; nested `Compound.volume` undercounts (sum `shape.solids()`); `is_valid`/`is_manifold` are **properties**.
- **`tools_structure`/`tools_urdf` sort before `tools_versioning`** — read `service.branches`/`store.write_guard`/`service.packages` **lazily in methods** via `getattr(service, …, None)`, never in `register()`. Neither pack appends to `gate_providers`.
- **`write_guard` must never fire against a source project** — resolution uses read-only accessors only (Decision 3).
- Tests must be **parallel-safe** (session-scoped `kernel` fixture; examples run on a copy; scratch under the given `--projects-dir`, never `~/AgentCAD`). Keep runs targeted (machine contended by PRD-006).
- **Do NOT** `uv sync`/`uv pip install`. scipy>=1.14 is already a dep (`pyproject.toml:22`).
- **Every commit** stages a `docs/changelog/NNNN-<slug>.md` entry (next number) and ends with the `Co-Authored-By: Claude <noreply@anthropic.com>` trailer.
