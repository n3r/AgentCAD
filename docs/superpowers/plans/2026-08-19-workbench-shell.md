# PRD-026 Workbench shell — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. One fresh subagent per slice; the controller (not subagents) runs `make test` and commits, one changelog per commit.

**Goal:** Replace the v0.1 shell primitives with a first-party dialog system, a ⌘K palette over the action registry *and* the live tool registry, a menu bar, resizable panels, a shortcut registry with a "?" overlay, and the `ui_open` tool + UX events.

**Architecture:** A new `frontend/js/shell/` layer of vanilla ES modules, each DOM module paired with a pure `*_model.js` that runs in node (tested from pytest, the `tree_model.js` pattern). One `actions.js` registry feeds palette, menus and shortcuts; registry tools are merged at query time from `GET /api/tools`. Server side: `core/tools_ui.py` (the `ui_open` pack) and `server/routes_ui.py` (`POST /api/ui/events`).

**Tech stack:** vanilla ES modules (no bundler, no `package.json`), CSS tokens in `frontend/css/app.css`, FastAPI route pack, pytest + node-in-pytest.

**Spec:** `docs/superpowers/specs/2026-08-19-workbench-shell-design.md` — read it first; every slice argues from it.

## Global constraints

- No framework, no bundler, no `package.json`, no new Python dependency.
- New JS lives in `frontend/js/shell/`; every module is importable in node (no top-level `document`/`window` access — DOM only inside `init()`/functions). Pure models export a `__shell__`-style test object (the `__treeModel__` precedent).
- Only `agentcad/kernel/` imports OCP — nothing here touches the kernel.
- Hosted mode: new routes are member-only by default; do **not** touch `PUBLIC_PATHS`; `/js/` is already public so `/js/shell/*.js` is served.
- Pack naming: `core/tools_ui.py` (loads at `ui`, registers unconditionally, no gate provider), `server/routes_ui.py` (`build_router(service, registry)`, default `/api` prefix).
- Subagents: `uv run pytest <paths>` for focused runs; **never** `uv sync`/`uv pip install`; **never** run mutating `git`; **never `Write` an existing file whole — use `Edit`** (other slices may be editing `main.js`/`app.css` concurrently).
- Every commit: `docs/changelog/NNNN-<slug>.md` citing the real `make test` count (the controller fills it).
