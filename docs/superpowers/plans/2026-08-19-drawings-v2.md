# PRD-014 Drawings v2 — implementation plan

Design: `docs/superpowers/specs/2026-08-19-drawings-v2-design.md`. TDD per slice;
the controller (not subagents) runs `make test` and commits, one changelog per
commit. Slices are **serial** — they all touch `handlers/drawing.py`, so parallel
edits would collide; Slice 1 is the foundation everything else builds on.

## Slice 1 — foundation: display list + sheets + title block (FR1, FR2, FR13 skeleton)
- Central `fmt(x)` float formatter (round-half-even 3dp, no `-0`, locale-free).
- Refactor `_build_svg` to build a **display list** of primitives (Line/Polyline/
  Circle/Arc/Text/Hatch + style enum) rendered by `SvgBackend` — behavior-
  preserving for the existing views/PMI/dims first (golden updated once).
- `handlers/_sheets.py`: `SHEETS` table (iso_a4..a0, ansi_a..d, landscape,
  default iso_a3), frame + zones drawn from the template.
- Uniform auto-scale from the preferred ladder; `scale` override + overflow
  warning; chosen scale in the title block + result.
- Data-driven title block (all FR2 fields).
- `manifest["drawing"]` section + `set_drawing_fields`/`get_drawing_fields`
  (whitelist: company/author/project_code/approved_by/notes).
- `_drawing_version(service, project) -> {ref, date}` (history.head/log/tags;
  content-hash + "-" with no repo); passed into the kernel request.
- Result skeleton: `{path, size_bytes, sheet, scale, views, sections, detected,
  warnings}` (+ pmi_rendered as today).
- Tests: title block renders each field; sheet formats produce right MediaBox;
  auto-scale picks a standard ratio; set/get fields validate; existing views
  unchanged but for the wrapper.
- **Opus.**

## Slice 2 — deterministic PDF + determinism guarantee (FR11, FR12)
- `handlers/_pdf.py`: pure-Python PDF writer over the display list (one page,
  Helvetica base-14, fixed object order, `fmt()` coords, no wall-clock/random id).
- `format: pdf` through `generate_drawing`; `GET …/drawing.pdf` route via
  `_drawing_result`.
- Determinism test: regenerate twice → equal sha256 for SVG **and** PDF; mutate a
  param then `project_restore` → original bytes (AC2). PDF strict-parse + page
  count (AC6 machine half).
- **Opus.**

## Slice 3 — sections & details (FR6, FR7)
- `section_outline` kernel handler: `b3d.section` → per-body 2D loops + bbox +
  warnings (misses the solid → warning + empty).
- Section view render: outline + 45°/alternating hatch, `A-A` label, cutting-
  plane arrows on parent; multiple sections `A-A`,`B-B`. Timeout scaled per
  section, pinned `affinity=part_id`.
- Detail views: labeled circle on parent + magnified clipped view (2D, no rebuild).
- Tests: a sectioned box hatches; multi-body alternates; a missing plane warns;
  a detail view magnifies.
- **Opus.**

## Slice 4 — centerlines, center marks, hole tables (FR8, FR9)
- Per-view circle detection (fix top-view-only); center marks in every view;
  coaxial centerlines (CHAIN) in side views.
- Hole table from `_records_on(shape)` (tag/X-Y/designation), detected fallback
  marked `detected`, tags at each hole; `hole_table` in the result.
- Tests: AC4 with PRD-010 metadata (designation + tags) and without (detected
  diameters); center marks appear in a side view.
- **Opus** (geometry-adjacent) — Sonnet if it stays table-formatting.

## Slice 5 — config tabulation (FR10)
- Render-time letter-variable assignment to PMI dims; config table (config ×
  variable + per-config mass); active config drives the views; degrade cleanly.
- Test: a multi-config part with `tabulate: true` renders letters + a table whose
  values match `build_configs`/measured extents.
- **Sonnet.**

## Slice 6 — frontend (drawings.js, Experience)
- Sheet-format `<select>`, view checkboxes, `Section…`/`Detail…` controls, PDF
  download; reuse `previewSeq`; no new modules.
- Verified in a real browser (screenshot) if the extension is available, else
  evidence-graded with the API/HTTP contracts tested.
- **Sonnet.**

## Slice 7 — acceptance tests + docs (AC1–AC7, deferrals recorded)
- AC1 (A3 sheet: frame + title block + A-A section + center marks), AC2 (SVG+PDF
  byte-stability + restore), AC4 (hole table both ways), AC6 (PDF parse + preview),
  AC7 (existing calls + golden). AC3/AC5 deferred (PRD-015 / recorded).
- Docs: `docs/agent-api.md` (new tools/args/result), `docs/part-authoring.md` or
  `docs/user-guide.md` (drawing fields, sheets, sections), `AGENTS.md`
  (Drawings-v2 gotchas: display-list/backends, PDF determinism, section_outline
  greenfield, DXF non-determinism, table-zone sharing), `docs/roadmap.md` on
  close-out.
- **Opus** (tests) + **Sonnet** (docs).

## Non-negotiables carried into every slice
- Only `agentcad/kernel/` imports OCP/build123d; the section handler is kernel-side.
- `affinity=part_id` on every kernel request the drawing path issues (no fan-out).
- Determinism: everything user-visible goes through `fmt()`; no wall-clock, no
  random ids; DXF excluded from byte-stability.
- Changelog per commit citing `make test — N passed`; subagents don't git/uv sync.
- Defer FR3/FR4/FR5 with an explicit PRD-015 warning, never a blank sheet.
