- **Commit:** pending

## Summary
`agentcad[usd]` enables a deterministic `.usda` stage export of parts and
assemblies; without the extra the format is absent from every schema (the
FEM gating pattern). FR11 of PRD-017.

## Changes
- `pyproject.toml`: `usd = ["usd-core>=26.8; platform_machine != 'aarch64'
  or sys_platform != 'linux'"]` — the marker is load-bearing: usd-core
  ships no linux-aarch64 wheel and `make test-linux` runs arm64; excluded
  platforms simply resolve no package and `usd_available()` stays False.
  `uv.lock` regenerated by the controller; the venv now carries
  `usd-core 26.8` (synced with `--extra usd --extra fem`).
- `core/usd_export.py`: `usd_available()` (`find_spec("pxr")`);
  `build_usd(items) -> bytes` (the `gltf.build_glb` twin — the pack owns
  the atomic write): one `.usda` text stage (diffable, byte-comparable),
  `metersPerUnit = 0.001` and `upAxis = "Z"` **declared, never
  converted**; mesh library authored once per `mesh_key` under an abstract
  `class` scope (never traversed/drawn), one referencing prim per
  instance. Poses are a single `xformOp:transform` matrix built from the
  glTF writer's quaternion — pxr's `rotateXYZ` composes `Rz·Ry·Rx` in our
  column convention (verified against `usdGeom/xformOp.cpp`), the reverse
  of the house intrinsic-XYZ, so an Euler op would silently mis-pose
  two-axis rotations. `displayColor` is **linear** (`srgb_to_linear`, the
  glTF choice), stated in the docstring and asserted numerically.
- `tools_xchange.py`: live `part_formats()`/`assembly_formats()` include
  `usd` iff available (enums, descriptions, routing, unknown-format
  message); import-time snapshots keep both-worlds tests stable. Fidelity
  `{"geometry": "mesh", "colors": "per_instance", "parametric": "none"}`.
- One slice-4 test updated: the unsupported-format message expectation is
  now derived from `assembly_formats()` instead of hardcoding the
  pre-USD list (controller fix — the live message is the correct
  behavior).
- The frontend needs nothing: slice 6's schema-driven menu picks `usd` up
  automatically when the extra is present.
